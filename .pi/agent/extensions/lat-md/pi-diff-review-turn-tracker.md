# Pi diff review turn tracker

This extension records per-turn bundles so later tooling can answer what the agent touched in the last turn.

## Responsibilities

It derives a turn id from the incoming prompt when possible, starts tracking at `agent_start`, records touched file paths for `edit` and `write`, records bash commands, finalizes the bundle at `agent_end`, and resets state on session boundaries.

When `pi-ssh` is active it consumes the shared `pi-ssh` session runtime, maps local tool paths onto the remote repo through that session, and captures remote file baselines/finals without a separate SSH helper lifecycle.

At finalize time it writes the canonical observed diff artifact and now also computes `observed_changed_paths` from the persisted patch identity, including omitted/binary stub identities. It may attach an optional fail-open `agent_change_report` generated by an external Codex summarizer, but that report is advisory only.

Its output is the `t`-mode history source used by [[pi-diff-review-tui]] and any other tooling that wants turn-scoped evidence.

## Invariants

Tracking should reset on session start, switch, and shutdown so bundles do not leak across sessions.

File touches and bash recordings should reflect actual tool calls from the current turn only.

`observed_changed_paths` is the canonical comparison set for later review tooling. It must stay distinct from `touched_paths`, which remains touch-attribution metadata.

If present, `agent_change_report` must be validated against the artifact namespace, recomputed for exact mismatches (`missing_from_observed`, `missing_from_agent_report`), and discarded cleanly on invalid or contradictory output.

If the prompt came from Discord and includes a message id, that id should be preferred as the turn identifier so cross-surface tracing stays possible.

## Failure and recovery

If no stable external id is available, generate a local turn id explicitly rather than leaving the turn untracked.

If the external summarizer times out, emits invalid JSON, reports out-of-namespace paths, or dirties the tracked repos, log a concise diagnostic and persist the canonical artifact without `agent_change_report`.

If a turn ends without meaningful touches, finalize a clean empty bundle instead of keeping stale state for the next turn.

## Change guidance

If you change bundle layout, canonical path derivation, advisory report schema, or turn-id rules, inspect [[pi-diff-review-tui]] because its `t` mode depends on the tracker’s last-turn bundle contract.

Keep this extension focused on capture and persistence; review UI policy belongs elsewhere.
